# CodeSpace 3.15.1 — Clean interface pass

- Removed long instructional and descriptive copy from the splash, composer, permission selector, Task Center and project-memory panels.
- Added compact question-mark help markers for optional explanations.
- Moved the permission shield into the second composer toolbar row.
- Simplified the permission selector to three clean options while preserving the explicit confirmation for Allow all.
- Kept permission modes, rule management, activity history, task queuing and recovery behavior intact.
- Added UI regression checks for placement, tooltip behavior and removed description elements.

The changes modify the current 3.15 source architecture; they do not restore an older composer or earlier UI design.
